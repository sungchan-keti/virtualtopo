# 지도 경로 좌표 추출기

지도에서 경로를 클릭하여 위도/경도 정보를 추출하고 CSV 파일로 저장하는 웹 애플리케이션입니다.

## 주요 기능

- 🗺️ **인터랙티브 지도**: OpenStreetMap 기반 지도 표시
- 📍 **경로 지점 추가**: 지도를 클릭하여 경로 지점 추가
- 📊 **실시간 좌표 목록**: 추가된 좌표를 실시간으로 확인
- 🔗 **경로선 표시**: 지점들을 연결하는 경로선 자동 생성
- 💾 **CSV 내보내기**: 수집한 좌표를 CSV 파일로 다운로드
- ↶ **실행 취소**: 마지막 지점 삭제 기능
- 🗑️ **전체 삭제**: 모든 지점 한 번에 삭제

## 사용 방법

### 1. 애플리케이션 실행

웹 브라우저에서 `index.html` 파일을 열거나, 로컬 서버를 실행합니다:

#### Python 3 사용:
```bash
python3 -m http.server 8000
```

#### Python 2 사용:
```bash
python -m SimpleHTTPServer 8000
```

#### Node.js 사용:
```bash
npx http-server
```

그런 다음 브라우저에서 `http://localhost:8000` 접속

### 2. 경로 지점 추가

1. 지도에서 원하는 위치를 클릭
2. 클릭한 위치에 번호가 매겨진 마커가 생성됨
3. 2개 이상의 지점을 추가하면 자동으로 경로선이 그려짐
4. 우측 패널에서 추가된 좌표 목록 확인 가능

### 3. 좌표 관리

- **마커 확인**: 우측 좌표 목록의 항목을 클릭하면 해당 마커로 이동
- **마지막 지점 삭제**: "↶ 마지막 지점 삭제" 버튼 클릭
- **전체 삭제**: "🗑️ 모두 지우기" 버튼 클릭

### 4. CSV 파일 저장

1. "💾 CSV 다운로드" 버튼 클릭
2. `route_coordinates_YYYYMMDD_HHMM.csv` 형식의 파일이 자동 다운로드됨

## CSV 파일 형식

생성되는 CSV 파일은 다음과 같은 구조를 가집니다:

```csv
번호,위도,경도
1,37.566500,126.978000
2,37.567123,126.979456
3,37.568234,126.980789
```

- **번호**: 경로상의 순서 (1부터 시작)
- **위도**: 소수점 6자리까지의 위도 좌표
- **경도**: 소수점 6자리까지의 경도 좌표
- **인코딩**: UTF-8 with BOM (한글 엑셀에서도 정상 표시)

## 기술 스택

- **Leaflet.js**: 오픈소스 지도 라이브러리
- **OpenStreetMap**: 무료 지도 데이터
- **Vanilla JavaScript**: 외부 프레임워크 없이 순수 자바스크립트 사용
- **HTML5/CSS3**: 반응형 UI 디자인
