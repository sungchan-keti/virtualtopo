# 지도 경로 좌표 추출기

지도에서 클릭으로 경로를 만들면 그 경로를 따라 균등하게 분할된 위도/경도 정보를 추출하고 CSV 파일로 저장하는 웹 애플리케이션입니다.

## 주요 기능

- 🖱️ **클릭으로 경로 그리기**: 지도를 클릭하여 정확한 지점 선택
- 🔢 **샘플 개수 설정**: 추출할 좌표 개수를 자유롭게 설정 (2~10,000개)
- 📊 **균등 분할 알고리즘**: 경로를 균등한 간격으로 정확하게 분할
- 📍 **시각화**: 클릭한 지점과 추출된 좌표를 지도에 표시
- 📏 **거리 측정**: 총 경로 거리, 마커 간 거리, 누적 거리 자동 계산
- 💾 **CSV 내보내기**: 좌표와 거리 정보를 CSV 파일로 다운로드
- 🗺️ **인터랙티브 지도**: OpenStreetMap 기반 지도 표시
- 📈 **실시간 좌표 목록**: 생성된 좌표와 거리 정보를 실시간으로 확인

## 사용 방법

### 1. 애플리케이션 실행

웹 브라우저에서 `index.html` 파일을 열거나, 로컬 서버를 실행합니다:

#### Python 3 사용:
```bash
python3 -m http.server 8000
```

#### Python 2 사용:
```bash
python -m SimpleHTTPServer 8000
```

#### Node.js 사용:
```bash
npx http-server
```

그런 다음 브라우저에서 `http://localhost:8000` 접속

### 2. 경로 그리기 및 좌표 추출

#### 단계별 가이드:

1. **샘플 개수 입력**
   - 상단의 "샘플 개수" 입력 필드에 원하는 개수 입력
   - 예: 50개, 100개, 1000개
   - 범위: 2 ~ 10,000개

2. **경로 그리기 시작**
   - "✏️ 경로 그리기 시작" 버튼 클릭
   - 지도에서 마우스 커서가 십자가 모양으로 변경됨

3. **지도에서 경로 만들기**
   - 지도에서 원하는 지점들을 클릭
   - 각 클릭마다 파란색 원형 마커가 추가됨
   - 클릭한 지점들이 파란색 선으로 연결됨
   - 원하는 만큼 지점을 계속 추가 가능

4. **경로 그리기 종료**
   - "⏹️ 경로 그리기 종료" 버튼 클릭
   - 총 경로 거리가 자동 계산되어 표시됨

5. **좌표 생성**
   - "⚡ 좌표 생성" 버튼 클릭
   - 경로를 따라 균등하게 분할된 좌표가 생성됨
   - 빨간색 원형 마커로 표시됨
   - 파란색 임시 마커는 제거됨

6. **CSV 파일 저장**
   - "💾 CSV 다운로드" 버튼 클릭
   - `route_coordinates_{개수}points_YYYYMMDD_HHMM.csv` 형식의 파일이 다운로드됨

### 3. 좌표 관리

- **좌표 확인**: 우측 패널에서 생성된 좌표 목록 확인
- **마커 포커스**: 좌표 목록의 항목을 클릭하면 해당 마커로 이동
- **전체 삭제**: "🗑️ 모두 지우기" 버튼으로 모든 데이터 삭제

## 작동 원리

### 균등 분할 알고리즘

1. **경로 수집**: 클릭한 지점들을 배열에 저장
2. **거리 계산**: Haversine 공식을 사용하여 각 세그먼트의 실제 거리 계산
3. **총 거리 산출**: 전체 경로의 총 거리 계산
4. **균등 간격 계산**: 총 거리를 샘플 개수로 나누어 간격 결정
5. **선형 보간**: 각 간격마다 위도/경도를 선형 보간하여 정확한 좌표 산출

### 거리 계산

- **Haversine Formula** 사용
- 지구의 곡률을 고려한 정확한 거리 계산
- 단위: 미터(m)

## CSV 파일 형식

생성되는 CSV 파일은 다음과 같은 구조를 가집니다:

```csv
번호,위도,경도,구간거리(m),누적거리(m)
1,37.566500,126.978000,0.00,0.00
2,37.566523,126.978123,22.45,22.45
3,37.566545,126.978246,22.45,44.90
...
100,37.570345,126.982567,22.45,2224.55
```

- **번호**: 경로상의 순서 (1부터 시작)
- **위도**: 소수점 6자리까지의 위도 좌표 (약 11cm 정밀도)
- **경도**: 소수점 6자리까지의 경도 좌표 (약 11cm 정밀도)
- **구간거리(m)**: 이전 지점과의 거리 (미터 단위, 소수점 2자리)
- **누적거리(m)**: 시작 지점부터의 총 거리 (미터 단위, 소수점 2자리)
- **인코딩**: UTF-8 with BOM (한글 엑셀에서도 정상 표시)

## 거리 측정 기능

### 총 경로 거리
- 경로 그리기 완료 시 자동으로 계산됨
- Haversine 공식을 사용한 정확한 실제 거리
- 헤더에 실시간 표시 (m 또는 km 단위)

### 마커 간 평균 거리
- 좌표 생성 시 자동으로 계산됨
- 총 경로 거리 ÷ (샘플 개수 - 1)
- 균등 분할의 정확도 확인 가능

### 구간 거리
- 각 지점과 이전 지점 사이의 거리
- 첫 번째 지점은 0m
- 좌표 목록에 주황색으로 표시 (+22.5 m)

### 누적 거리
- 시작 지점부터 각 지점까지의 총 거리
- 좌표 목록에 녹색으로 표시 (누적: 450 m)
- CSV 파일에 포함되어 데이터 분석 가능

### 거리 표시 단위
- **1km 미만**: 미터(m) 단위 표시
- **1km 이상**: 킬로미터(km) 단위 표시
- 자동 변환으로 가독성 향상

## FAQ

### Q: 샘플 개수를 얼마로 설정해야 하나요?
**A:** 용도에 따라 다릅니다:
- **간단한 경로**: 50~100개
- **정밀한 분석**: 500~1000개
- **매우 정밀한 작업**: 1000개 이상

### Q: 경로가 너무 복잡하면 어떻게 하나요?
**A:** 여러 구간으로 나누어 그린 후 CSV를 결합하거나, 샘플 개수를 늘려주세요.

### Q: 좌표의 정확도는 어느 정도인가요?
**A:** 소수점 6자리로 약 11cm의 정밀도를 제공합니다.

### Q: 모바일에서도 사용 가능한가요?
**A:** 네, 터치로 지점을 클릭하여 경로를 만들 수 있습니다.
